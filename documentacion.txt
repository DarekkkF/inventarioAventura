AVENTURAS DEL SUR

Este proyecto es una página para un ecoparque. Permite ver las actividades disponibles, reservar un cupo y revisar las reservas. También tiene un panel para administrar las experiencias, categorías y usuarios.

Está hecho con Django y MySQL. Para el diseño usa Bootstrap y para buscar y ordenar las tablas usa DataTables. Hay que tener internet para que carguen esas dos bibliotecas.

Cómo abrir el proyecto

1. Descomprimir la carpeta y abrirla en Visual Studio Code.
2. Abrir una terminal de PowerShell en la carpeta donde está manage.py.
3. Crear el entorno e instalar lo necesario:

python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt

4. Tener MySQL funcionando. Abrir en Workbench el archivo .sql que está en respaldos y ejecutarlo para importar la base inventario_aventura. Hacerlo en una instalación de prueba, porque el respaldo puede reemplazar tablas de una base con ese mismo nombre.
5. Copiar .env.example y cambiar el nombre de la copia a .env. Dentro hay que poner el usuario y la contraseña del MySQL del computador donde se va a probar. El nombre de la base debe ser inventario_aventura. El respaldo no crea el usuario de MySQL, así que se debe usar uno que tenga acceso a esa base.
6. En la terminal ejecutar:

python manage.py migrate
python manage.py runserver

7. Abrir http://127.0.0.1:8000/ en el navegador.

Estas son las cuentas de la página, no las de MySQL. El administrador entra desde el mismo login que los demás usuarios.

Qué puede hacer cada usuario

El administrador puede crear, editar y eliminar usuarios, categorías y experiencias. También puede ver todas las reservas y marcar los pagos como confirmados.

El guía puede crear experiencias y editar las que él creó. No puede eliminar experiencias ni administrar categorías o usuarios.

El turista puede ver el catálogo, reservar y revisar sus propias reservas. Puede cancelar una reserva si la actividad todavía no ocurre y el pago está pendiente. Las cuentas creadas desde el registro público quedan como turistas.

Datos de prueba

Se incluyeron dos guías con cuatro experiencias cada uno y dos turistas con tres reservas cada uno. Si se hicieron pruebas después, las cantidades del respaldo pueden haber cambiado.

Para comprobar que funciona

Entrar con cada rol y revisar que solo aparezcan sus opciones. Probar crear y editar una experiencia, buscar en las tablas y reservar una actividad. No debe dejar reservar dos veces la misma experiencia ni superar el cupo máximo. Si una actividad tiene fecha pasada o está desactivada, no aparece en el catálogo.

También se pueden ejecutar las pruebas con:

python manage.py test --settings=inventarioAventura.test_settings

Estas pruebas usan una base temporal y no cambian los datos guardados en MySQL.

Respaldo

El archivo .sql de la carpeta respaldos contiene las tablas y los datos para importar el proyecto en otro computador. La contraseña local de MySQL no se incluye en la entrega.
